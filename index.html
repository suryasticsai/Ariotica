About Ariotica Aigent

Ariotica is a 100% free, self-healing AI engineering pipeline built entirely on GitHub Actions. It turns issues into working applications without servers, databases, or complex infrastructure.

🏁 Parallel Model Race

Fires the prompt at Groq, Gemini, OpenRouter, and Pollinations simultaneously. The first one to pass the tests wins.

🩺 Self-Healing Loop

Runs generated code in a headless browser (JSDOM), catches console errors, and automatically repairs itself up to 3 times.

🧠 RAG Memory

Uses a zero-dependency BM25 search engine to remember past builds and recall skills, ensuring style consistency across apps.

📱 Installable PWA

Automatically injects a manifest and service worker, allowing every generated app to be installed on iOS and Android.

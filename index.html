    How the Engine Works

    01 🏁 Model Race

    Groq, OpenRouter, and HuggingFace compete in parallel. The first model to pass the test suite wins, and the losers are instantly cancelled.

    02 🩺 Self-Healing Loop

    Apps are rendered in a headless DOM. Runtime errors are captured and fed back to the AI to patch, up to 3 rounds, before committing.

    03 ⚒️ Sandboxed Forge

    The AI writes its own Node.js plugins, tests them in a secure `vm` sandbox, and saves them to a proposal folder for human approval.

    04 🕸️ Web Scraper (RAG)

    Uses Jina AI Reader to scrape live websites, converting them to markdown to use as a design and feature blueprint for the app.

    05 🧠 Skill Library

    Teaches itself via markdown cheatsheets. It auto-injects verified skills (like WebRTC or Canvas) into the prompt when relevant.

    06 🧾 Cryptographic Receipts

    Every build generates a JSON receipt with SHA-256 hashes of all files, the winning model, and a CSP security policy.

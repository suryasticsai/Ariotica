    How the pipeline works

    01Model race

    Several providers answer at once. The first answer that passes the tests wins, the rest are cancelled.

    02Self-healing

    The app runs in a headless DOM. Errors are fed back to the model and patched, up to three rounds.

    03Receipts

    Hashes, checks and the winning model are recorded for every build so changes are detectable.

    04Installable

    Each app ships a manifest and service worker, so it installs on phones like a native app.
